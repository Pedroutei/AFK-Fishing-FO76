Requirements
VB CABLE INPUT
EasyFishing.ba2
fishing sound.ba2
silent legendary.ba2
Under Game settings disable C.A.M.P. Weather and Intense Weather Effects

1. Launch easyFishing.exe (1080p)
2. Open Sound Settings
3. Open Volume Mixer
4. Set the Default Output Device to CABLE INPUT (VB-Audio Virtual Cable)
5. Launch the Game
6. Ensure that FO76 audio is at 100%
7. Change the default Ouput Device back to the original setting in Volume Mixer
8. Change the FO76 Audio Settings, both MASTER and EFFECTS volume at 100%, and everything else should be at 0%
9.Press F5 to start the easyFishing.exe script
10.Run autoReel.py
11.Wait around 10 seconds before clicking e
12.Start Fishing
